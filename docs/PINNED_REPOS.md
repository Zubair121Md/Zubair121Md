# Pinned Repositories Strategy

**Goal:** When a recruiter, founder, or investor lands on [github.com/Zubair121Md](https://github.com/Zubair121Md), the six pins should read like an AI + operations portfolio — not a GTM/outreach dump.

Pin order is intentional: **AI → Business Analysis → ERP → AI systems → Research → Analytics.**

Outreach / LinkedIn poster / B2B growth tools are **not** pinned.

---

## Why this order maximizes impact

1. **AI first** — Matches the headline in under two seconds.  
2. **Business Analysis second** — Positions you as decision-systems, not only code.  
3. **ERP third** — Proves you ship serious operational software.  
4. **More AI fourth** — Depth without diluting BA/ERP.  
5. **Research fifth** — Narrative and taste.  
6. **Analytics sixth** — Closes the loop: data → decisions.  

**Do not pin:** outreach engines, LinkedIn posters, slideshows, forks, or unfinished class repos.

---

## How to pin on GitHub

1. Open https://github.com/Zubair121Md  
2. Click **Customize your pins**  
3. Select the six repos in the order above  
4. Save  

Each pinned repo should use [`templates/REPO_README_TEMPLATE.md`](../templates/REPO_README_TEMPLATE.md).
